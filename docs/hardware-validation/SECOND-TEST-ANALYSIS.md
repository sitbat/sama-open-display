# 第二次测试画面分析

> 历史测试分析；末尾的待验证项已在后续真机测试中处理，现行结论见 [协议文档](../../PROTOCOL.md)。

照片显示整屏规则彩色竖条。原因不是屏幕损坏，也不是固件问题，而是把已经排版好的 720×1568 纵向
缓冲区旋转成 1568×720 后直接交给仍按 720 像素步长扫描的协议，导致每行边界错位。

已经修正为两个明确的坐标空间：

- 用户、GUI 与媒体画布：1568×720 横屏；
- USB 协议扫描缓冲区：720×1568；
- 转换：横屏画布顺时针旋转 90°，得到固定尺寸协议缓冲区；
- 编码器在发送前强制检查输入、输出尺寸，错误尺寸会被拒绝。

新的横屏测试卡和仪表盘已离线生成，并通过 27 项测试，等待再次授权真机验证。
