# 首次测试卡方向分析

> 历史测试分析；末尾“尚待第三次测试”描述当时进度，后续结果见 [验证汇总](HARDWARE-VALIDATION.md)。

用户照片确认：

- 整帧完整，未见花屏或明显裁切；
- 红、绿、蓝、黄以及 RGB/CMY 色条均正确，BGRA 通道顺序正确；
- 逻辑画面整体逆时针旋转 90°；
- TL 红映射到物理左下，TR 绿映射到物理左上；
- BL 蓝映射到物理右下，BR 黄映射到物理右上。

第二次测试证明不能直接旋转已经排版完成的 720×1568 纵屏缓冲区，否则会因扫描步长不匹配产生竖条。

正确修正：应用先在 1568×720 的物理横屏画布排版，再顺时针旋转成严格的 720×1568 协议缓冲区。
编码器现在会同时校验输入画布和输出缓冲区尺寸，尚待第三次真机测试确认。
