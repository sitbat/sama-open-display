# SAMA 6.5 英寸小屏真机验证结果

- USB：`VID_1D6B&PID_A065`，测试时为 COM5；
- HELLO：`chs_65inch.dev1_rom1.91`；
- 用户画布：1568×720 横屏；
- 协议扫描缓冲区：720×1568；
