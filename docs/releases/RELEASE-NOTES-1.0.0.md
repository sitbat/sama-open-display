# SAMA Open Display 1.0.0

首个公开 GitHub Release。SAMA Open Display 是用于给兼容的 SAMA USB 小屏显示自定义内容的非官方开源工具，与品牌方无隶属或背书关系。

## 下载与安装

下载 `SAMA-Open-Display-1.0.0-win-x64.msi`，在 Windows 11 x64 上运行安装向导。可以选择安装目录；默认为所有用户安装到 `Program Files`，需要管理员权限。安装后可从开始菜单启动，也可在 Windows“已安装的应用”中卸载。安装包尚未签名，Windows 可能显示发布者提示。

MSI SHA-256：`7058AD51360E4851A1331F7D4EDFE1DD089CA594FFC6ADA0ABD3C9612D11E8F2`

## 主要功能

- WinUI 3 界面，预览并发送内置主题、图片或文本画面。
- 适配已验证的 6.5 英寸 SAMA USB 小屏，支持单帧发送与持续差分刷新；写入前核对设备标识。
- 可导入 `.sodpkg` 布局主题和数据接口插件，支持依赖声明和批量管理。
- 可设置开机自启、启动后持续发送、托盘行为；恢复上次内容与主题选择。
- 插件及设置保存到当前用户的 `%LOCALAPPDATA%\SAMA Open Display\`，与安装目录分离；卸载程序会保留用户数据。

## 验证与限制

构建时通过 Python 单元测试与 WinUI Release x64 编译。MSI 完成安装规则验证；解包的 656 个程序文件与原始发行目录逐一进行 SHA-256 比对，全部一致。以管理员权限测试了“所有用户”模式安装到自选目录、开始菜单快捷方式、后端启动和卸载清理。尚未对这个发布构建进行长时间真机运行测试。

目前仅对设备标识 `chs_65inch.dev1_rom1.91` 的设备完成真机通信验证。其他型号尚未验证；详细范围见 [项目状态](../PROJECT.md)。
