# SAMA Open Display 0.2.0 开发快照

> 历史版本记录；功能和待办均以 0.2.0 发布时为准。现行状态见 [项目状态](../PROJECT.md)。

这是已经完成单帧真机验证的安全开发版本，默认不会打开或写入 COM5。

已验证：

- 自动识别当前 COM5 主屏和 COM4 辅助设备；
- 1568×720 横屏图片、文字和实时系统仪表盘，转换为 720×1568 协议缓冲区；
- GIF 帧时长处理以及 OpenCV 视频解码/帧率限制；
- 连续画面的最小变化区域检测；
- Rev-C 全帧字节计划和强制硬件授权门；
- 真机 HELLO 已返回 `chs_65inch.dev1_rom1.91`；
- 33 项单元测试覆盖协议、媒体、配置、安全门、双坐标空间、播放、分块发送与取消；
- 可在无网络、无构建隔离模式下生成 Python wheel；
- 提供 Windows PyInstaller 构建脚本。

已真机验证：HELLO、全屏测试卡、物理横屏转换、颜色通道和完整画幅。

尚待验证：`CC` 局部更新坐标、长时间动态播放和 Windows 独立 EXE。
