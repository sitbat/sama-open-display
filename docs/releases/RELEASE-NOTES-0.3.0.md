# SAMA Open Display 0.3.0

> 历史版本记录；功能和待办均以 0.3.0 发布时为准。现行状态见 [项目状态](../PROJECT.md)。

本版本完成当前 6.5 英寸小屏的真机全屏协议验证。

已验证：

- 自动发现 COM5 主屏和 COM4 辅助设备；
- HELLO 返回 `chs_65inch.dev1_rom1.91`；
- 1568×720 横屏画布正确转换为 720×1568 协议扫描缓冲区；
- 四字节 BGRA、249/250 字节分块及全帧命令参数；
- 单帧总写入 4,536,000 字节，实测约 1.0–1.2 秒；
- 任意图片、文字、系统仪表盘、GIF 和视频帧解码；
- CLI/GUI 单帧发送以及低帧率媒体/仪表盘播放入口；
- 写入前确认、设备身份校验、尺寸检查、取消和端口关闭；
- 从原厂程序集还原 ROM >= 1.89 的 `CC` 压缩差分记录及 8 字节元数据；
- 旧的 5/8 英寸矩形 `CC` 实现和真机脚本已移除/禁用；
- 39 项自动测试全部通过。

下一阶段：在单独明确授权后验证新 `CC` 差分编码，构建并测试 Windows 独立 EXE，执行长时间稳定性测试。
