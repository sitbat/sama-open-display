# 项目状态与目标

SAMA Open Display 是一款非官方开源工具，目标是在兼容的 SAMA USB 小屏上显示用户选择的画面，并让主题作者通过插件自由组合布局与数据。项目与 SAMA 品牌方没有隶属、授权或背书关系。

## 当前可用

| 功能 | 状态 |
| --- | --- |
| 自动检测 6.5 英寸目标设备，预览主题、图片和文本 | 已实现 |
| 单帧发送与持续发送；主题差分更新 | 已在当前设备上验证 |
| WinUI 3 界面、亮暗色、托盘、开机自启、内容和设置恢复 | 已实现 |
| `.sodpkg` 布局主题和数据接口、批量管理、前置依赖 | 已实现 |
| 长时间运行及更多设备型号兼容性 | 仍需验证 |

当前真机基线为 `VID_1D6B&PID_A065` 显示链路、`VID_1A86&PID_CA65` 辅助链路，握手返回 `chs_65inch.dev1_rom1.91`。程序以 1568 × 720 横屏画布生成内容，转换为 720 × 1568 的传输缓冲区。端口号随系统变化，不能把测试记录中的 COM 编号当成固定配置。

## 使用与安全边界

检测和本地预览不会向屏幕发送画面。WinUI 中点击发送按钮会直接启动写入；用户也可以在设置中主动开启启动后自动持续发送。所有写入都要经过设备握手和精确身份核对。命令行另需指定 `--write-hardware` 和完整设备标识。

第三方布局主题是声明式内容；第三方数据接口可包含 Windows EXE，会以当前用户身份运行。界面在安装此类插件前显示警告。主题声明数据接口为前置后才能读取其字段；运行中的主题只调用自己声明的可执行前置。详见 [插件规范](../PLUGIN_SPEC.md)。
